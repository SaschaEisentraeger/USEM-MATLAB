\section{Highlights (separate file \texttt{highlights.tex})}

\begin{itemize}
  \item A Lagrange basis lowers the Vandermonde condition number up to $10^4$-fold at $p=16$.
  \item Hybrid trial space: complete polynomials in skew, others in reference coordinates.
  \item The hybrid element equals the conventional spectral element on straight-sided meshes.
  \item Optimal convergence on curved meshes where the original metric element diverges.
  \item Eigenvalues with negative real part of the original metric element are removed.
\end{itemize}
