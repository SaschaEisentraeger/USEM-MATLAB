\section*{Data availability}
The implementation (MATLAB/GNU Octave), the scripts that produce every number and figure of this paper (\texttt{manuscript/studies}) and the raw data (\texttt{manuscript/data}) are contained in the USEM code repository. The generated tables (\texttt{manuscript/generated}) are written by these scripts, and the source of every table is noted in the LaTeX source.
