\section{Verification}\label{sec:verification}
\Cref{tab:verification} summarises the cross-checks of the study routines against the
code base (\texttt{matlab/cyl\_verify.m}, full output in \texttt{results/verification.txt}).
The study was run with GNU Octave~8.4 (MATLAB is not available in the build environment);
three Octave stand-ins (\texttt{matlab/octave\_compat}) replace MATLAB functions used by the
code base (\texttt{contains}, \texttt{decomposition}, the third output of
\texttt{unique(\dots,'stable')}). Compared with the first run of this study (monomial basis
of the metric functions), the \PP\ results are bitwise identical. The \PM\ trial space is the
same, so only round-off differs: on the meshes without folds, \PM\ errors more than ten times
above the round-off level (\cref{sec:poly}) change by at most $7\,\%$; errors at the round-off
level and errors on folded meshes, where the \PM\ solution is dominated by the amplified
round-off, change in either direction (smaller in $235$, larger in $127$ of the $362$ values that
changed by more than $0.1\,\%$, by up to a factor $10.5$). $7$ \PM\ cases per problem (folded
meshes, $p\ge6$) are now rejected. \Cref{tab:folded} lists the number of folded elements.
