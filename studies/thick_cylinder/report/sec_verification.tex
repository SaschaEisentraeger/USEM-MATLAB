\section{Verification}\label{sec:verification}
\Cref{tab:verification} summarises the cross-checks of the study routines against the
code base (\texttt{matlab/cyl\_verify.m}, full output in \texttt{results/verification.txt}).
All computations were run with \texttt{MATLAB} R2026a. Errors at the round-off level
(polynomial field for $p\ge5$, $p\ge7$ on the finest meshes) and the \PM\ errors on strongly
distorted and folded meshes, where the solution is dominated by the amplified round-off
(\cref{sec:poly}), depend on the floating-point environment: compared with a run on another
platform they differ by up to a factor $22$, whereas all other errors above $10^{-6}$ agree to
$1\,\%$. $7$ \PM\ and $6$ \PH\
cases per problem (folded meshes, $p\ge6$) are rejected by the code base. \Cref{tab:folded}
lists the number of folded elements.
