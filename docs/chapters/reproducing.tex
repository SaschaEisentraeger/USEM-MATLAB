\chapter{Reproducing the results of the paper}
\label{ch:reproducing}

The code on this branch is the minimal code base of the paper \enquote{Unsymmetric
spectral elements with hybrid trial space} (\code{manuscript/}). It contains only
the routines that are needed to reproduce the numbers, tables and figures of the
paper. The general-purpose code (analysis driver, time integration, modal and
frequency-domain analyses, \texttt{ABAQUS} readers for loads and boundary conditions,
visualization) is available on the branch \code{main}.

\section{Requirements}

All studies were computed with \texttt{MATLAB} R2026a. The thick-cylinder study
needs the Symbolic Math Toolbox (\code{cyl_problem}, derivation of the manufactured
fields); all other studies and the tests need base \texttt{MATLAB} only. The run
scripts need \code{bash}, the post-processing Python 3 without further packages, and
the manuscript a \LaTeX\ distribution with \code{pgfplots}. The meshes in
\code{studies/*/mesh} are under version control; regenerating them needs
\code{gmsh} and its Python interface.

\section{Running the studies}

The scripts in \code{manuscript/studies} run several batch sessions side by side and
write their logs to \code{manuscript/studies/logs}:
\begin{lstlisting}[style=shell]
cd manuscript/studies
bash run_calibration.sh   # Gauss rules of all studies (data/quadrature)
bash run_reruns.sh        # mesh-level studies, thick cylinder
bash run_element.sh       # element-level studies, panel, timing
bash run_postprocess.sh   # plot data and tables (data/, generated/)
\end{lstlisting}
The order of the first two scripts matters, because the studies read the calibrated
rules. \code{run_element.sh} runs the timing study last and alone; its numbers
depend on the machine.

The results of the paper are computed with the meshes in \code{studies/*/mesh/inp}.
A rerun with these meshes and \texttt{MATLAB} R2026a on the same machine reproduces
all files except \code{timing.dat} byte for byte. The generators
\code{gen_panel_meshes.py} and \code{gen_cylinder_meshes.py} document how the meshes
were made. With \code{gmsh} 4.15.2, they reproduce the panel meshes exactly. The
cylinder meshes have the same topology and differ in the node coordinates by up to
$7\cdot10^{-10}$. Results with these regenerated meshes agree except for values
dominated by round-off, which is amplified by the Vandermonde matrix: the errors of
\PM\ at high degree and on folded meshes, e.g., $7.5\cdot10^{-8}$ instead of
$9.3\cdot10^{-8}$ at $\alpha=30^\circ$, $N=8$ and $p=8$, and the reciprocal condition
numbers of singular matrices. The same kind of change has to be expected on another
machine or \texttt{MATLAB} version.

\section{Eigenvalue and transient studies}

The paper examines the spectrum and the free vibration of the discrete system, since
they reveal the loss of stability of the unsymmetric system. The consistent mass
matrix (\code{ms_Me}), the assembly of $\matr K$ and $\matr M$ (\code{ms_assemble_KM})
and the trapezoidal rule (\code{ms_transient}) are therefore part of
\code{manuscript/studies}. The code base in \code{code/} itself contains no dynamics.
