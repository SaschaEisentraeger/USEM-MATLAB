\chapter{Theory: The unsymmetric spectral element method}
\label{ch:theory}

This chapter describes the formulation as it is implemented in
\code{code/subroutines}. The literature is collected in \cref{ch:literature}.

\section{Problem}

The code solves linear plane elasticity (plane stress or plane strain) on a
domain $\Omega$ with thickness 1. In Voigt notation, the equation of motion,
Hooke's law and the strains read
\begin{equation}
  \matr L^{\T}\bm\sigma + \vect b = \rho\,\ddot{\vect u},\qquad
  \bm\sigma = \matr C\,\bm\varepsilon,\qquad
  \bm\varepsilon = \matr L\,\vect u =
  \begin{bmatrix}\varepsilon_{xx}\\ \varepsilon_{yy}\\ \gamma_{xy}\end{bmatrix},
  \qquad
  \matr L = \begin{bmatrix}\partial_x & 0\\ 0 & \partial_y\\
                           \partial_y & \partial_x\end{bmatrix},
\end{equation}
with prescribed displacements $\bar{\vect u}$ on the Dirichlet boundary
$\Gamma_\mathrm{u}$ and prescribed tractions $\bar{\vect t}$ on the Neumann
boundary $\Gamma_\mathrm{t}$. $\matr C$ is the $3\times3$ plane stress or plane
strain matrix, obtained from the three-dimensional Hooke matrix
(\code{PlaneStressConstitutiveMatrices}, \code{PlaneStrainConstitutiveMatrices}).

\section{Petrov-Galerkin weak form}

The classical (Bubnov-Galerkin) finite or spectral element uses the same
isoparametric shape functions to interpolate the displacements (trial
functions) and to weight the equilibrium equation (test functions). The
unsymmetric element uses two different sets \parencite{Rajendran2010technique},
see \cref{tab:spaces,fig:spaces}.

\begin{table}[htbp]
  \centering
  \caption{Shape functions of the unsymmetric element.}
  \label{tab:spaces}
  \begin{tabular}{@{}lll@{}}
    \toprule
    Role & Shape functions & Property \\
    \midrule
    test (weighting) & parametric, $N_i(\xi,\eta)$ &
      continuous across element edges \\
    trial (displacement) & metric, $M_j(x,y)$ &
      complete polynomials in $x$ and $y$ \\
    \bottomrule
  \end{tabular}
\end{table}

\begin{figure}[htbp]
  \centering
  \input{figures/test-trial-spaces}
  \caption{Parametric test functions are defined on the reference element,
    metric trial functions in the corotational skew coordinates $(s,t)$ of the
    physical element.}
  \label{fig:spaces}
\end{figure}

The displacements are interpolated with the metric functions, the virtual
displacements with the parametric functions. The principle of virtual work then
reads
\begin{equation}
  \int\limits_{\Omega} \bm\varepsilon(\vect w)^{\T}\matr C\,\bm\varepsilon(\vect u)\dd\Omega
  + \int\limits_{\Omega} \rho\,\vect w^{\T}\ddot{\vect u}\dd\Omega
  = \int\limits_{\Omega} \vect w^{\T}\vect b\dd\Omega
  + \int\limits_{\Gamma_\mathrm{t}} \vect w^{\T}\bar{\vect t}\dd\Gamma
  \label{eq:weakform}
\end{equation}
for every virtual displacement $\vect w$ (parametric) that vanishes on
$\Gamma_\mathrm{u}$. Both sets of shape functions are interpolatory at the same
nodes, so the nodal displacements are the unknowns, as in the classical element.
Because the two sides of the weak form use different functions, the element
matrices are \emph{unsymmetric}.

\subsection*{Why the element is insensitive to mesh distortion}

If the exact displacement field is a polynomial of total degree $\le p$ in
$(x,y)$, the metric functions reproduce it exactly on every element, whatever
its shape, so the strains and stresses are exact as well. The parametric test
functions are continuous across the element edges, so the exact stresses
satisfy the weak form \eqref{eq:weakform} with these test functions (this is the
principle of virtual work for the exact solution). Hence the exact nodal values
solve the discrete equations: the solution is exact on any mesh, provided the
integrals are evaluated exactly (\cref{sec:quadrature}). This is the distortion
immunity of Rajendran's unsymmetric elements
\parencite{Rajendran2003novel,Rajendran2010technique}, here for arbitrary $p$.
The classical isoparametric element loses this property as soon as the element
geometry is not a parallelogram, because the isoparametric functions then no
longer contain all polynomials of degree $p$ in $(x,y)$; quadratic fields on
elements with curved edges are the standard example \parencite{Lee1993effects}.
The metric functions need not be continuous across element edges; continuity
is provided by the test functions.

\section{Parametric (test) shape functions}

\code{ShapeFunctions2D_SEM(xi, eta, p)} builds products of one-dimensional
Lagrange polynomials through $p+1$ nodes in each direction. The node
distribution is selected with \code{p.ndist} (\code{nodal_distribution.m}):
\begin{center}
  \begin{tabular}{@{}cl@{}}
    \toprule
    \code{ndist} & nodes \\
    \midrule
    1 & equidistant \\
    2 & Gauss-Lobatto-Legendre (GLL), the default (spectral elements) \\
    3 & Gauss-Lobatto-Chebyshev (GLC) \\
    \bottomrule
  \end{tabular}
\end{center}

\paragraph{Geometry.} The element geometry is described with the same degree-$p$
shape functions as the displacements. The positions of the element
nodes, however, are computed from the 4-node (bilinear) or 8-node (Serendipity)
element of the input mesh (\code{pSpectralElement_NodesTopology}): every node is
placed at the image of its reference coordinates under the bilinear or
Serendipity map of the input element. The degree-$p$ map
interpolates this map exactly, so all its higher-order terms vanish and the
geometry is the bilinear or Serendipity geometry of the input mesh, whatever $p$
is: edges are straight (4-node input) or parabolic (8-node input, $p\ge2$).
The elements are therefore subparametric for $p>2$, and increasing $p$ improves
the approximation of the displacements, but not that of the geometry. This is a
limitation of the code base: isoparametric elements would require the nodes to
be placed on the exact geometry (e.g.\ by Gordon-Hall blending of exact boundary
curves, as done outside the code base in \code{studies/thick_cylinder}).
Curved boundaries are therefore represented only as accurately as by the input
mesh; a degree-$p$ geometry would require an input mesh of degree $p$.

\paragraph{Local node numbering.}
For degree $p$ an element has $(p+1)^2$ nodes: the 4 corners, then the interior
nodes of edge~1 ($\eta=-1$), edge~2 ($\xi=+1$), edge~3 ($\eta=+1$) and edge~4
($\xi=-1$), each in the direction of increasing $\xi$ or $\eta$, and finally the
interior nodes row by row ($\xi$ fastest), see \cref{fig:nodes}. Global degrees
of freedom (DOFs) are interleaved: node $n$ has $u_x$ at DOF $2n-1$ and $u_y$ at DOF
$2n$ (\code{Topology_DoF_2D}).

\section{Metric (trial) shape functions in skew coordinates}

\code{ShapeFunctions2D_Metric(xQ, yQ, xN, yN, p)} builds shape functions that
are interpolatory at the element nodes $(x_k,y_k)$ in physical space, in four
steps:
\begin{enumerate}
  \item \textbf{Skew coordinates} (\code{CorotationalSkewCoordinates},
    \cite{Xie2016Modified}; \cite{Yuan1993New}). The skew coordinates $(s,t)$
    are Cartesian coordinates measured along the two element axes at the element
    centre, scaled with the element size: with the centre
    $\vect x_0 = \vect x(0,0)$ and the Jacobian $\matr J_0$ there,
    \begin{equation}
      \begin{bmatrix} s\\ t\end{bmatrix} = \matr J_0^{-\T}\,(\vect x - \vect x_0).
    \end{equation}
    They are linear in $x$ and $y$, move and rotate with the element, and
    coincide with $(\xi,\eta)$ on a parallelogram.
  \item \textbf{Polynomial space.} The shape functions are polynomials of degree
    $p_\upxi$ in $s$ and $p_\upeta$ in $t$ (all products $s^a t^b$ with $a\le
    p_\upxi$, $b\le p_\upeta$, the space $Q_p(s,t)$). For good conditioning they
    are written in a Lagrange basis $\ell_a(\tilde s)\,\ell_b(\tilde t)$, where
    $\tilde s$, $\tilde t$ are the skew coordinates scaled to the interval
    $[-1,1]$ of the nodes; the shape functions themselves do not depend on the
    basis (\cref{ch:metric-basis}).
  \item \textbf{Interpolation.} The coefficients follow from the conditions
    $M_j(\vect x_k) = \delta_{jk}$ at the nodes, a linear system with the
    generalized Vandermonde matrix $\matr V$ (values of the basis at the nodes).
  \item \textbf{Derivatives.} The derivatives with respect to $x$ and $y$
    follow from those with respect to $s$ and $t$ with the constant matrix
    $\matr J_0^{-1}$.
\end{enumerate}
Properties (all covered by \code{tests/unit/MetricShapeFunctionsTest.m}):
\begin{itemize}
  \item \textbf{Completeness.} $s$ and $t$ are linear in $x$ and $y$, so every
    polynomial of total degree $\le p$ in $(x,y)$ is a polynomial of degree $\le p$
    in $(s,t)$ and is reproduced exactly on any element shape.
  \item \textbf{Frame invariance.} Rigid-body motions and uniform scaling of the
    element do not change the shape functions. Monomials in centroid-shifted
    global coordinates (\code{method = 0}, \cite{Rajendran2003novel}) are also
    complete, but depend on the orientation of the element for $p\ge2$
    \parencite{Ooi2008Remedies}.
  \item \textbf{Affine elements.} On a parallelogram the metric and the
    parametric functions coincide, so the element is the classical spectral
    element and $\matr K_e$ is symmetric.
  \item \textbf{Unisolvence.} The interpolation conditions can be singular for
    special node positions on strongly distorted elements, e.g.\ when two nodes
    coincide \parencite{Ooi2008Remedies}. The code stops with an error in this
    case; with \code{p.nodeShift}~$>0$ it moves one node of such an element
    slightly instead (\cref{sec:node-shift}).
\end{itemize}

\subsection*{Singular interpolation matrices}
\label{sec:node-shift}

On strongly distorted elements, the geometry map of the input element can
place two element nodes onto each other, or the nodes can take a position in
which the polynomials of the trial space cannot interpolate arbitrary nodal
values (the generalized Vandermonde matrix is singular). By default the code
stops with an error message (\code{CheckCoincidentNodes},
\code{CheckUnisolvent}). With \code{settings.p.nodeShift} $> 0$ (e.g.\
$10^{-3}$), \code{ShiftSingularNodes} instead moves one node of such an element
by this fraction of the element size: an interior node if the element has one
(so the boundary of the domain stays exact), the one that gives the best
conditioning, in a fixed direction towards the element centre. The step is
doubled until the interpolation matrix is regular, and a warning names the
element and the node. This is a pragmatic remedy: the geometry changes by about
the shift near the moved node, while completeness and frame invariance are
kept. A slight perturbation of the nodal coordinates is one of the remedies for
singular interpolation matrices that \textcite{Ooi2008Remedies} discuss (after
Liu and Gu, for meshless point interpolation); their own remedy, a random
rotation of the coordinate system, does not help here, because the metric
functions in skew coordinates are frame invariant.

\code{method=2} (\code{p.metricMethod=2}) uses the hybrid space instead of
$Q_p(s,t)$: all polynomials of total degree $\le m=\min(p_\upxi,p_\upeta)$ in
the scaled skew coordinates $(\tilde s,\tilde t)$, $P_m(\tilde s,\tilde t)$,
complemented by parametric functions of $(\xi,\eta)$
(\cref{sec:metric-hybrid}). It has the same
completeness and invariance, equals the parametric space on all straight-edged
elements and avoids the exponential growth of the Lebesgue constant of
$Q_p(s,t)$ on distorted elements.

\section{Element matrices}

The Jacobian is used in the convention (\code{Jacobi_Matrix})
\begin{equation}
  \matr J = \begin{bmatrix} \partial x/\partial\xi & \partial y/\partial\xi\\
                            \partial x/\partial\eta & \partial y/\partial\eta
            \end{bmatrix}.
\end{equation}

\paragraph{Stiffness} (\code{Ke_2D}):
\begin{equation}
  \matr K_e = \int\limits^{1}_{-1}\int\limits^{1}_{-1}\matr B_\mathrm{L}^{\T}\matr C\,
  \matr B_\mathrm{R}\,\det(\matr J)\dd\xi\dd\eta,
\end{equation}
where $\matr B_\mathrm{L}$ holds the derivatives of the parametric (test) and
$\matr B_\mathrm{R}$ those of the metric (trial) functions. The product
$\det(\matr J)\,\matr B_\mathrm{L}$ is computed with the adjugate of $\matr J$,
$\det(\matr J)\,\matr J^{-1}$, so $\det(\matr J)$ never appears in a
denominator; this is Rajendran's third condition for distortion immunity. The
rule assumes $\det(\matr J) > 0$ (no inverted elements). $\matr B_\mathrm{R}$ is
evaluated at the physical positions of the Gauss points. Consequences:
\begin{itemize}
  \item Rigid-body modes lie in both the right and the left null space of
    $\matr K_e$, and $\operatorname{rank}(\matr K_e) = n_\mathrm{dof}-3$.
  \item $\matr K_e$ is unsymmetric unless the element is a parallelogram.
\end{itemize}

\paragraph{Mass} (\code{Me_2D}, and \code{KMe_2D} together with the stiffness):
\begin{equation}
  \matr M_e = \int\limits^{1}_{-1}\int\limits^{1}_{-1}\rho\,\matr N^{\T}\matr M\,
  \det(\matr J)\dd\xi\dd\eta ,
\end{equation}
where $\matr N$ holds the parametric and $\matr M$ the metric functions.
\begin{center}
  \begin{tabularx}{\linewidth}{@{}lL@{}}
    \toprule
    \code{mass_matrix} / \code{lumping} & mass matrix \\
    \midrule
    1 & consistent (unsymmetric) \\
    2 & nodal quadrature with GLL points: exactly diagonal, because both $N_i$
        and $M_j$ are interpolatory at the nodes (requires \code{ndist = 2}) \\
    3 & row-sum lumping \\
    4 & Hinton-Rock-Zienkiewicz (HRZ) lumping (diagonal scaling) \\
    \bottomrule
  \end{tabularx}
\end{center}

\subsection*{Numerical integration}
\label{sec:quadrature}

\code{Ke_2D}, \code{Me_2D} and \code{KMe_2D} use $2p_\upxi\times2p_\upeta$
Gauss-Legendre points (other numbers can be passed to \code{Ke_2D} and
\code{Me_2D}). Whether this integrates the element matrices exactly depends on
the element shape, because the metric functions are polynomials in $(x,y)$, and
$x$, $y$ and $\det(\matr J)$ are polynomials in $(\xi,\eta)$ whose degree grows
with the distortion. The integrands of the default trial space $Q_p(s,t)$ are
polynomials in $(\xi,\eta)$, so a finite Gauss rule is exact; its size was
determined numerically (smallest rule that reproduces the matrices of a
40-point rule to $10^{-12}$, single elements of \cref{fig:test-elements}):
\begin{center}
  \begin{tabular}{@{}lccc@{}}
    \toprule
    element (input mesh) & $\matr K_e$ exact with & $\matr M_e$ exact with &
      $2p$ sufficient? \\
    \midrule
    parallelogram & $p+1$ & $p+1$ & yes \\
    straight edges (4-node) & $\lceil 3p/2\rceil$ & $\lceil (3p+2)/2\rceil$ &
      yes, except $\matr M_e$ for $p = 1$ \\
    curved edges (8-node), $p\ge2$ & $2p+1$ to $2p+2$ & $2p+2$ to $2p+3$ &
      no \\
    \bottomrule
  \end{tabular}
\end{center}

  \centering

  \label{fig:test-elements}
\end{figure}

For straight edges the numbers follow from the polynomial degrees: $x$ and $y$
are linear in $\xi$ and in $\eta$, so $s^a t^b$ has degree up to $2p$ in each
direction, $\det(\matr J)$ degree 1 and a test function degree $p$; the mass
integrand thus has degree $3p+1$ per direction, which needs
$\lceil(3p+2)/2\rceil$ points. On curved elements, the degrees double because
$x$ and $y$ are quadratic, and $2p$ points under-integrate both matrices
(\textcite{Eisentraeger2025unsymmetric} discuss the numerical integration of
unsymmetric elements in detail).

The exactness of the patch tests is not affected: a polynomial displacement field
of degree $\le p$ produces stresses of degree $\le p-1$ in $(x,y)$, and the
integrand of the corresponding stiffness terms has degree $\le 3p-1$ per
direction even on curved elements, which $2p$ points integrate exactly. This is
why the patch tests of \cref{ch:testing} are passed to machine precision on all
meshes. For the hybrid space (\code{method = 2}), the gradients of the
parametric part contain $\matr J^{-1}$, so the stiffness integrand is a rational
function on non-affine elements and no Gauss rule integrates it exactly.

\paragraph{Loads.} Edge loads (pressure, traction) and body loads are
integrated with the parametric (test) functions (\code{CreatePress},
\code{CreateTraction}, \code{CreateBload}, \code{CreateGravity}), consistent with
the weak form \eqref{eq:weakform}.

\paragraph{Post-processing.} Displacements, strains and stresses inside the
elements are evaluated with the metric (trial) functions
(\code{Calc_results}, \code{Results_Stress_Strain}).

\section{Practical implications of unsymmetric matrices}
\label{sec:unsymmetric}

\begin{itemize}
  \item \textbf{Linear solvers.} $\matr K$ is unsymmetric: use LU
    decomposition (\texttt{MATLAB}'s \texttt{\textbackslash} or \code{decomposition}),
    not Cholesky.
  \item \textbf{Eigenvalues.} For unsymmetric $\matr K$ and $\matr M$ the
    eigenvalues $\omega^2$ of the free vibration problem
    $\matr K\bm\phi = \omega^2\matr M\bm\phi$ are not guaranteed to be real and
    positive. \textcite{Wang2022Temporal} show that negative eigenvalues can
    occur for non-symmetric discretizations of elastodynamics; complex
    eigenvalue pairs are possible in general, a possibility that
    \textcite[Ch.~8]{Ooi2006unsymmetric} names for the unsymmetric 8-node element
    as an open question for free vibration problems. \code{ModalAnalysis}
    returns the moduli.
  \item \textbf{Time integration.} Energy is not conserved, and schemes that are
    unconditionally stable for symmetric systems (e.g.\ the trapezoidal rule of
    the Newmark family) can become unstable
    \parencite{Wang2022Temporal,Zaehringer2026On}. Check dynamic results
    critically.
\end{itemize}
